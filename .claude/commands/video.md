description: Turn a video idea into hooks, a short script and a caption
---

Video idea: $ARGUMENTS

Using `prompts/video-ideas.md` for my niche, hook formulas and tone:

1. Write 5 hook options (first 3 seconds, under 12 words each), each using a different formula. Mark your favourite.
2. Write a 30–45 second script: hook, the problem, the automation shown on screen, the result, call to action.
3. List on-screen text for each beat, and what to screen-record.
4. Write a caption under 60 words ending with "Comment [KEYWORD] and I'll send you the build."
5. If the CRM database is set up, save it to content_items as status Scripted.
