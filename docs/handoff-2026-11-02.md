## Gotchas learned (do not repeat)

- **A project hook blocks any bash command that reads or prints the secrets file, and even one that mentions its name in the command text** (for example inside a heredoc comment). Use `npx tsx --env-file=../.env script.mts` for test scripts (that form works), say "the env file" in comments and docs written from bash, and create files that must mention it with the Write tool.
- **AI token limits**: `askStructured` throws when a reply hits `max_tokens`. 1,500 was too small for the fit analysis and the pipeline step. Use 4,000 or more for structured replies with lists.
- Pure `lib/*Math.ts` modules that import each other must import with the `.ts` extension, or `npm test` (node strip-types) cannot load them. Test files are `.mjs`: no TypeScript syntax (no `!`).
- Files with `"use server"` may export only async functions and every exported function needs `requireLogin()` (a read helper once did not).
- Postgres `bigint` ids arrive as strings: wrap in `Number()`. macOS `sed -i` needs `-i ''`; use `python3` for multi-line edits.
- Apify rejects a run cap under $0.50; the real spend is kept down by the number of results asked for. Budget checks use the cost recorded in `content_runs`.
- Testing pattern that worked: a stand-in Apify server via `APIFY_API_BASE`, and throwaway rows (prefixed `ZZ`) deleted in a `finally`, with before/after row counts printed. Never leave test data in the live database.
